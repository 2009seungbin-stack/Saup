# 상품 상세페이지·섬네일 제작

운영자/관리자 로그인 후 **상품 제작** 메뉴를 엽니다. 기존 상품의 상품명·SKU·판매가를 가져오거나 직접 입력하고, 상품 사진과 확인된 설명을 넣어 자동 생성합니다. 상품 등록이나 외부 마켓 게시를 실행하지 않습니다.

1. 등록 상품을 선택해 불러오거나 상품명을 입력합니다. 다른 상품을 불러오면 기존 사진과 설명을 초기화해 잘못 섞이지 않게 합니다.
2. JPG/PNG/WebP 사진을 최대 6장 추가합니다. 첫 사진이 대표 사진이며, 사진마다 대표 지정·삭제가 가능합니다. 장당 10MB/2,400만 화소 이하이며 흰 배경, 최대 1600px의 JPEG로 정리합니다.
3. 한 줄 소개, 브랜드, 상품 정보, 상세 설명, 구매 전 안내를 입력합니다. 비운 항목은 생략합니다. 가격은 표시를 선택했을 때만 포함합니다. 인증·효능·후기·원산지를 추측해 생성하지 않습니다.
4. 세이지/샌드/잉크 디자인을 선택합니다. 섬네일은 800/1000/1200px 정사각형, 상세페이지는 860/1000px 너비를 선택합니다. 높이는 사진과 텍스트에 따라 계산하며 14,000px를 넘으면 내용을 줄이도록 안내합니다.
5. **상세페이지·섬네일 자동 생성**을 누릅니다. 긴 상세 이미지 1개와 사진 중심/상품명 강조/카드형 섬네일 3개가 만들어집니다. 입력을 바꾸면 이전 출력은 무효화되어 다시 생성해야 합니다.
6. 미리보기에서 PNG 하나를 받거나 **전체 ZIP 다운로드**를 누릅니다. ZIP에는 PNG 4개, `detail.html`, 편집 파일, 사용 안내가 들어 있습니다. HTML과 detail.png는 같은 폴더에 두고 열면 됩니다.

편집 파일에는 입력 텍스트와 사진이 포함됩니다. **편집 파일 저장/열기**로 다른 기기에서도 이어서 작업할 수 있습니다. 메뉴 간 이동은 편집 내용을 유지하지만, 새로고침·로그아웃·창 종료 후에는 파일을 다시 열어야 합니다. 제작 입력과 사진은 이 기능에서 서버로 업로드하거나 자동 저장하지 않습니다. 등록 상품 정보 조회는 기존 인증 API를 사용합니다.

이 버전은 **사진 기반 자동 조판 프로그램**입니다. 생성형 AI 이미지 제작, 배경 제거, 여러 상품 일괄 제작, 클라우드 보관, 외부 마켓 자동 게시와 특정 마켓의 최신 심사 규격 인증은 포함하지 않습니다. 출력 크기는 일반 선택 옵션이며 마켓별 적합성을 보증하지 않습니다. 상세 HTML은 이미지 기반이며 검색용 텍스트 상세페이지를 대신하지 않습니다.

## 검증

`tests_browser/test_creative_studio.py`는 실제 Chromium/Canvas로 사진을 입력하고 ZIP을 내려받아 CRC, 파일 목록, PNG 크기를 검사합니다. 긴 설명, HTML 이스케이프, 편집 파일 복구, 이전 출력 무효화, 메뉴 이동 유지, 390px 미리보기, 잘못된 파일 거부, viewer UI 제한도 확인합니다. 기존 Docker 브라우저 수용 테스트에 포함됩니다. 실제 상품 사진의 판매 적합성과 모든 폰트/브라우저 조합은 별도 확인 대상입니다.
